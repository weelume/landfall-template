# 素材来源与权利边界

运行照片来自参考演示站 https://impartial-goal-555890.framer.app/ 的公开 Framer CDN，按内容摘要和原始 URL 逐项记录于 `.tpl/asset-sources.json`。所有照片本地托管，使用原站已有的 2048px 尺寸变体；未包含 Framer 徽章、编辑器或推广栏素材。

**照片许可证尚未确认**。此来源记录只证明取得位置和文件字节，不能证明著作权、商标权或商业再分发许可。公开上架、售卖或商用前须取得相应授权，或替换为已授权照片并重新验收。

MiSans 为真实 Regular/Bold（400/700）字重，采用小米字体许可，见 `public/templates/landfall/fonts/misans/LICENSE-SOURCE.md`。Poppins 为 Latin 400/600/700，采用 SIL OFL。Instrument Serif 常规及斜体从 Google Fonts 本地化，保留 OFL；Bricolage Grotesque 和 DM Mono 仅保留为原站可选排版参考。所有许可证随运行素材保留，不从字体工具或框架许可证推断图片权利。
